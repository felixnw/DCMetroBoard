API Key

A WMATA API key is required for this application to receive live train data.

Time Buffer

Optionally hide trains that are arriving sooner than a given number of minutes.
Note that there may not be estimates for trains too far out.

min

Train Quantity

Optionally set a custom max number of upcoming trains displayed. The default is 4.
Note that there may not always be as many trains as the entered number.

trains

Stations

Select one or more stations to view upcoming trains for.
Note that some stations have two options, depending on lines.
